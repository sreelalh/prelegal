# prelegal

A platform for drafting common legal agreements.

> **Status: Work in Progress 🚧**  
> This project is currently in active development and is scheduled to be completed in **1 week**.

## Overview
Prelegal is designed to simplify and streamline the drafting of common legal contracts and agreements.

## Project Structure
- `frontend/`: Next.js web application for drafting legal agreements (includes Mutual NDA creator prototype).
- `templates/`: Curated markdown legal agreement templates sourced from Common Paper (CC BY 4.0).
- `catalog.json`: Metadata catalog of available agreement templates.

## Quick Start (Frontend)
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to access the Mutual NDA generator.
